# Polski Grammar Matrix

Польская грамматика для русскоязычного технаря: маленький словарь, видимая система преобразований и карточки с целыми предложениями.

## Тренировка как в Anki

При открытии появляется лицевая сторона карточки: **исходное предложение + операция**. Произнеси ответ вслух или про себя, нажми **«Показать ответ»**, сравни его с эталоном и выбери **Снова / Трудно / Хорошо / Легко**. Можно переключиться на печатный ответ. После проверки ответ фиксируется.

- **Цепочка предложений** сохраняет один набор слов на пяти карточках: вижу → прошедшее → отрицание → другой владелец → говорю о.
- **По расписанию** выбирает навык, которому пора на повторение. FSRS хранит состояние навыка; при следующем повторении генерируется другой пример.
- **Отдельный навык** позволяет отдельно практиковать падеж, время, местоимение, вопрос или множественное число.
- **Таблица под рукой** показывает все падежные формы текущей группы слов, не сбрасывая карточку.

Пример цепочки:

```text
To jest moja piękna żona.
→ Widzę moją piękną żonę.
→ Widziałem moją piękną żonę.
→ Nie widziałem mojej pięknej żony.
→ Nie widziałem ich pięknej żony.
→ Mówię o ich pięknej żonie.
```

На обороте показаны эталон, допустимые варианты, изменения слов и объяснение. Пробел раскрывает ответ, клавиши 1–4 ставят оценку, Enter проверяет печатный ответ. При фокусе в обычной кнопке работают её стандартные клавиши активации.

В цепочке оценки тоже обновляют FSRS, но следующий шаг идёт сразу для практики. Режим «По расписанию» учитывает даты повторений. Оценка «Снова» планирует повторение навыка, а не заучивание той же фразы.

## Таблицы и схема

- Карта: смысл → конструкция → падеж → согласование всей группы.
- Дерево мужского Biernika: человек / животное / предмет; отдельно `kolega` на `-a`.
- Все 7 падежей с русскими названиями, вопросами, конструкциями и целыми предложениями.
- Выбор существительного, прилагательного, владельца и числа; формы пересчитываются из общего грамматического движка.
- Сравнение типов склонения на `mąż / kolega / pies / dom / żona / książka / dziecko`.
- Матрица времён по лицам, числу и роду; таблица процесса и результата.
- Личные местоимения внутри конструкций и притяжательные `mój / twój / jego / jej / nasz / wasz / ich`.
- Переход из таблиц прямо в тренировку соответствующего навыка.

Сейчас: 16 навыков, 12 наборов слов для цепочек, 14 существительных в таблицах. Редкие конструкции B2 и свободный синтаксический анализ пока не реализованы. Печатная проверка сравнивает с эталоном и перечисленными допустимыми вариантами; регистр, лишние пробелы и конечная пунктуация не влияют на результат, польские диакритические знаки важны.

## Прогресс

Данные хранятся в localStorage этого браузера и адреса. Старый прогресс сохраняется, для новых навыков создаются карточки. В устном режиме точность определяется самооценкой: «Снова» — ошибка; остальные оценки — вспомнил. В печатном режиме точность определяется проверкой ответа независимо от выбранного интервала.

Экспорт JSON доступен на вкладке «Прогресс». Импорт через интерфейс пока не добавлен. Локальная версия и опубликованный сайт имеют разные хранилища. Приватное окно очищает данные после закрытия всех приватных окон.
