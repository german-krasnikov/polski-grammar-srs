# Polski Grammar Matrix

Тренировка польской грамматики и слов для русскоязычных: целые предложения, видимые преобразования форм и интервальное повторение. Локальная разработка расширяет приложение до нескольких языков; сейчас подготовлена только пара польский–русский.

**[Открыть тренажёр в браузере](https://german-krasnikov.github.io/polski-grammar-srs/)** — установка и локальный сервер не нужны.

## Тренировка как в Anki

В текущей локальной версии при первой встрече с навыком сначала показаны исходное предложение и короткое вводное наблюдение выбранной подачи. Нажми **«Перейти к заданию»**: появятся операция и поле ответа. При следующих встречах задание открывается сразу. Произнеси ответ вслух или про себя, нажми **«Показать ответ»**, сравни его с эталоном и выбери **«Повторить»** или **«Вспомнил»**. Можно переключиться на печатный ответ. После проверки ответ фиксируется; даже при ошибке время следующего повтора выбираешь сам.

- **Цепочка предложений** сохраняет один набор слов на пяти карточках: вижу → прошедшее → отрицание → другой владелец → говорю о.
- **По расписанию** выбирает навык, которому пора на повторение. FSRS хранит состояние навыка; при следующем повторении генерируется другой пример.
- **Отдельный навык** позволяет отдельно практиковать падеж, время, местоимение, вопрос или множественное число.
- **Таблица под рукой** показывает все падежные формы текущей группы слов после вводного шага, не сбрасывая карточку. До перехода к заданию она скрыта, чтобы не подсказать ответ.

Пример цепочки:

```text
To jest moja piękna żona.
→ Widzę moją piękną żonę.
→ Widziałem moją piękną żonę.
→ Nie widziałem mojej pięknej żony.
→ Nie widziałem ich pięknej żony.
→ Mówię o ich pięknej żonie.
```

До ответа старая изменяемая часть исходного предложения выделена красным; после ответа новая форма выделена другим цветом и подчёркиванием. Пара «Было → Стало» и подписи позволяют видеть замену без опоры только на цвет. На обороте также показаны допустимые варианты и объяснение. Пробел раскрывает ответ, клавиши 1–2 ставят оценку, Enter проверяет печатный ответ. В нативных приложениях для Android и iPhone/iPad по области оценок можно провести влево для «Повторить» или вправо для «Вспомнил»; кнопки доступны всегда.

В локальной веб-версии можно переключать подачу «Схемы и логика» / «Живые ситуации» прямо на карточке: меняются вводное наблюдение, подсказка перед ответом и порядок разбора после него; введённый ответ и расписание сохраняются. Это способы подачи, а не диагноз «типа мозга».

## Слова в локальной веб-версии

Вкладка «Слова» предлагает отдельные карточки русский → польский и польский → русский. Отмечай готовые слова галочками, произноси или печатай ответ, открывай перевод, форму и пример, затем сам выбирай «Повторить» или «Вспомнил». Направления имеют разные расписания; снятие галочки сохраняет историю. После открытия карточки на мобильном экране можно провести влево или вправо для оценки.

Каталог показывает уровни и частотные срезы топ-100/500/1000. Сейчас после языковой сверки доступны **32 карточки**: 7 из топ-100, 23 из топ-500, 30 из топ-1000 и две вне этого частотного списка. Остальные леммы видны как задел и недоступны для тренировки. Метки A1/A2 — локальные группы курса, не официальная сертификация CEFR; уровень и частотный ранг независимы. Можно добавить свои слова и примеры, исправить или удалить их, экспортировать и импортировать JSON словаря. Это отдельный файл прогресса от грамматических карточек. Частотный список: [Leksjo / NKJP, CC BY 4.0](https://github.com/KubaCiolo/leksjo-dane); метод сверки и происхождение — в [атрибуции](courses/pl-ru/ATTRIBUTION.md).

В цепочке оценки тоже обновляют FSRS, но следующий шаг идёт сразу для практики. Режим «По расписанию» учитывает даты повторений. Оценка «Повторить» планирует повторение навыка, а не заучивание той же фразы.

## Таблицы и схема

- Карта: смысл → конструкция → падеж → согласование всей группы.
- Дерево мужского Biernika: человек / животное / предмет; отдельно `kolega` на `-a`.
- Все 7 падежей с русскими названиями, вопросами, конструкциями и целыми предложениями.
- Выбор существительного, прилагательного, владельца и числа; формы пересчитываются из общего грамматического движка.
- Сравнение типов склонения на `mąż / kolega / pies / dom / żona / książka / dziecko`.
- Матрица времён по лицам, числу и роду; таблица процесса и результата.
- Личные местоимения внутри конструкций и притяжательные `mój / twój / jego / jej / nasz / wasz / ich`.
- Переход из таблиц прямо в тренировку соответствующего навыка.

Сейчас: 16 навыков, 12 наборов слов для цепочек, 14 существительных в таблицах. Редкие конструкции B2 и свободный синтаксический анализ пока не реализованы. Печатная проверка сравнивает с эталоном и перечисленными допустимыми вариантами; регистр, лишние пробелы и конечная пунктуация не влияют на результат, польские диакритические знаки важны.

## Запуск

Команды Vite ниже запускают сохранённый React-эталон. Опубликованная браузерная версия собирается из Kotlin; её запуск, аудиоархивы и нативные сборки описаны в [kotlin/README.md](kotlin/README.md).

Node.js 22.12+ (в `.nvmrc` указан 22); также Node.js 20.19+ или 24+.

```bash
npm ci
npm run dev
```

Проверки и сборка:

```bash
npm test
npm run typecheck
npm run build
npm run preview
```

Данные курса хранятся в [courses-biome/](courses-biome/) и проверяются контрактами [dsl/biome.project](dsl/biome.project). Biome генерирует типизированные Kotlin-строки; правила оценивания экзаменов и переходов сеанса задаются DSL. React-исходники сохранены как эталон миграции.

Переход на Kotlin Multiplatform описан в [Plans/Kotlin/Plan.md](Plans/Kotlin/Plan.md). Общую Kotlin-логику используют браузер и нативные хосты Android, iPhone/iPad и macOS. Команды сборки, перенос прогресса и границы проверок — в [kotlin/README.md](kotlin/README.md); текущая работа — в [плане следующей сессии](Plans/Architecture/NEXT-SESSION-PLAN.md). ## Экзамены

В разделе «Экзамен» доступны официальные письменные варианты B1/B2/C1: аудирование, чтение, грамматика и письмо. Можно выбрать отдельный раздел или пройти четыре части подряд с официальными лимитами времени. Задания, иллюстрации, записи и веса ответов берутся из проверенных исходных материалов; [доставка аудио](Plans/Architecture/WEB-EXAM-AUDIO-DELIVERY-PLAN.md) воспроизводится через архивы с закреплёнными хешами.

Письмо и допустимые ответы, требующие решения экзаменатора, остаются на ручной проверке. Результат отдельно показывает подтверждённые баллы и баллы, ожидающие проверки; при наличии непроверенных ответов он остаётся предварительным. [Браузерная приёмка](Plans/Architecture/P9-PUBLICATION-BROWSER-INDEPENDENT-EVIDENCE.md) фиксирует проверенную сборку и ограничения.

## Прогресс

Данные хранятся в localStorage этого браузера и адреса. Старый прогресс сохраняется, для новых навыков создаются карточки. В устном режиме точность определяется самооценкой: «Повторить» — ошибка; «Вспомнил» — успешное воспоминание. В печатном режиме точность определяется проверкой ответа независимо от выбранного интервала. Старые оценки «Трудно» и «Легко» в сохранённом прогрессе остаются читаемыми.

Экспорт JSON доступен на вкладке «Прогресс». Импорт через интерфейс пока не добавлен. Локальная версия и опубликованный сайт имеют разные хранилища. Приватное окно очищает данные после закрытия всех приватных окон.
