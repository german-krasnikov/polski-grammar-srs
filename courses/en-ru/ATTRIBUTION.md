# English/Russian course data

`frequency-top1000.json` contains ranks and counts derived from [`enwiki-2023-04-13.txt`](https://github.com/IlyaSemenov/wikipedia-word-frequency/blob/798ea9062d6e5aed1fa87deeeda1cd99d5b37903/results/enwiki-2023-04-13.txt), a word-frequency aggregation of the English Wikipedia dump generated by [IlyaSemenov/wikipedia-word-frequency](https://github.com/IlyaSemenov/wikipedia-word-frequency) (script: strip punctuation/digits, keep words used in at least 3 distinct articles). The repository, including its generated `results/` files, is licensed [MIT](https://github.com/IlyaSemenov/wikipedia-word-frequency/blob/master/LICENSE) — no ShareAlike obligation, consistent with the preference already applied to `pl-ru/frequency-top1000.json`.

This project copied only the first 1,000 ranked word/count pairs, retaining their order. On 2026-09-28, the source file at commit `798ea9062d6e5aed1fa87deeeda1cd99d5b37903` had SHA-256 `e2071140a49a6c40c732bd68c36836ef13c0978233fb3d5e1b2a3c2d34faef59`; the local `frequency-top1000.json` produced from its first 1,000 lines has SHA-256 `f64d9dcebdff358135aec3b6031763c553f3cbc8f2603e525ea40c82c5050253`.

## Sources considered and rejected (EnRuPackPlan.md §3.1)

Two other candidates were checked before this one and rejected on verified facts, not assumption:

- **hermitdave/FrequencyWords** (`content/2018/en/en_50k.txt`, OpenSubtitles-derived). The repo's own `README.md` states plainly: "MIT License for code. **CC-BY-SA-4.0 for content.**" The frequency *data* itself is ShareAlike-licensed — the exact risk this project avoids for commercial content (same reasoning as `pl-ru/ATTRIBUTION.md`'s choice of a CC BY, non-ShareAlike source). Separately, the raw file is subtitle-tokenized and its top ranks contain non-word fragments (`'s`, `'t`, `'m`, `'re`, a bare `don` split off `don't`) rather than clean lemmas or word-forms — a second, independent reason to reject it.
- **Peter Norvig's `count_1w.txt`** (Google Web Trillion Word Corpus, LDC-distributed). Norvig's page grants an explicit MIT license only for *the accompanying Python code*, not for the count files themselves, which are described only as "derived from" an LDC-distributed corpus with no explicit redistribution license stated for the derived counts. Unverifiable permission is treated the same as no permission; not used.

The Wikipedia-derived source above is the only one of the three with an explicit, verified, non-ShareAlike license covering the actual frequency data.

## Note on word-form vs. lemma

Unlike `pl-ru/frequency-top1000.json` (built from NKJP's lemma-annotated corpus, so `być` stands for all its inflected forms), this English list ranks raw Wikipedia word-forms: inflections such as `is`/`are`/`was`/`were` or `word`/`words` appear as separate entries rather than being merged under one lemma. This is a property of the source, not an error — recorded here so downstream editorial selection (`vocabulary-editorial.json`) accounts for it rather than assuming lemma-normalized ranks.

Frequency rank and language-learning level answer different questions, same as for pl-ru: this file is a discovery list, not a set of ready-to-study cards. Card selection, translation and review happen in `vocabulary-editorial.json` (a later task).

## Known extraction artifacts (linguist self-check, 2026-09-28)

The source's stripping of punctuation/digits does not fully clean wiki-markup remnants. Four ranked entries are not real English words: `gt` (rank 485, likely `&gt;`), `lt` (rank 492, likely `&lt;`), `p` (rank 702) and `f` (rank 704) (likely stripped page/folio abbreviations). Two entries keep a possessive apostrophe despite the source's stated apostrophe normalization: `women's` (rank 432) and `men's` (rank 643). None of these were edited or removed — the file stays byte-faithful to the source's first 1,000 ranked lines, same policy as `pl-ru/frequency-top1000.json` ("retaining their order"); filtering is editorial judgment that belongs to `vocabulary-editorial.json` card selection, not to this discovery list. Recorded here so that later task does not treat these six ranks as real lemmas.
