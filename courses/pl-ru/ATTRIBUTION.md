# Polish/Russian course data

The Polish forms, Russian meanings and skill texts in `course.json` were extracted from the existing project. The reference chain, tense/aspect comparisons and male accusative examples are adapted from its grammar matrix; the added before-form phrases are generated from the project's Polish morphology and checked against it. The 32 vocabulary example sentences in this package were authored for this course. Level labels on these 32 entries are local editorial groupings, not official CEFR certifications.

`frequency-top1000.json` contains ranks and counts derived from [`nkjp-frekwencja.csv`](https://github.com/KubaCiolo/leksjo-dane/blob/01782aa92cc842d0d3199079eba47ecbf05879e1/dane/nkjp-frekwencja.csv) by Leksjo, based on the manually annotated NKJP 1.2 one-million-word subcorpus. The source identifies the frequency data as [CC BY 4.0](https://github.com/KubaCiolo/leksjo-dane/blob/01782aa92cc842d0d3199079eba47ecbf05879e1/LICENSE.md). This project copied only the first 1,000 ranked lemmas and counts, retaining their order; it did not use the separate Wiktionary-derived archaic-word dataset. On 2026-09-24, the first 1,000 CSV records at commit `01782aa92cc842d0d3199079eba47ecbf05879e1` matched all 1,000 local lemma/count pairs exactly. The source CSV SHA-256 was `4cd43eb6acb22fe19c83cdcdd408dc8519f0b583627ee3f00f31079871a208ca`; the local JSON SHA-256 was `4549d27b90ec4bb3e1ca9db55fcdd2256b91e28a25f0474cbd55f6a94e2a9a70`.

Frequency rank and language-learning level answer different questions. The frequency file is a discovery list; only entries with a prepared translation, form and example in `course.json` are offered as ready-to-study cards. All 32 initial cards underwent an independent AI-assisted language cross-check against WSJP PAN on 2026-09-24, with eight wording/form clarifications and a second check of those changes; the [editorial report](../../Plans/Kotlin/Stage-Vocabulary-Editorial-Tester.md) records each source and decision. This is not a human CEFR assessment; A1/A2 remain local groupings.
