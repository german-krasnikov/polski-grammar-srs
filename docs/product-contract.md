# Согласованная система обучения

Источник: [общая беседа «Система польской грамматики»](https://chatgpt.com/share/6aa6ab0d-95fc-83ed-9fec-087b75b19cf1) и уточнения пользователя 13 сентября 2026 года.

Существенное уточнение: первоначальный архив технически запускался, но не реализовывал обсуждённый способ обучения. Пользователю нужны карточки Anki с целыми предложениями, таблицы и структура для русскоязычного человека с техническим мышлением.

| Требование | Реализация |
| --- | --- |
| Небольшой фиксированный набор слов, внимание на правилах | 12 осмысленных наборов для цепочек, выбираемых в интерфейсе |
| Исходное предложение → операция → целое предложение | Все карточки используют законченные исходные и целевые предложения |
| Двусторонняя карточка Anki | Ответ скрыт; раскрытие эталона; устная самооценка или печатная проверка |
| Одна мысль проходит несколько преобразований | Пять связанных шагов; ответ предыдущей карточки становится исходным предложением следующей |
| Интервальное повторение | FSRS на уровне навыка; очередь по датам, четыре оценки, локальное сохранение |
| Видно, какие части изменились | На обороте пары «до → после», причина изменения, формула |
| Система вместо разрозненных правил | Карта зависимостей: конструкция → падеж → вся группа; дерево мужского Biernika |
| Таблицы всегда доступны | Контекстная таблица рядом с карточкой + отдельная матрица |
| Род, число, падеж, согласование | 7 падежей, singular/plural, все пять родовых категорий, притяжательное + прилагательное + существительное |
| Времена и лица | Таблица 9 подлежащих с настоящим, прошедшим, будущим; выбор рода для первого и второго лица |
| Местоимения | Личные формы в конструкциях и семь притяжательных владельцев |
| Русскоязычная опора | Русские названия, вопросы, объяснения, сравнение знакомых русских и польских конструкций |

Не заявляется полный курс B1/B2: текущая поставка покрывает описанную механику и базовое ядро, а не ранее предложенное последующее расширение до 50–70 навыков.

Польские формы используют таблицы проекта. Для новых притяжательных форм проверены [WSJP: twój](https://wsjp.pl/haslo/podglad/54537/twoj) и [учебная таблица Masaryk University](https://is.muni.cz/el/1421/podzim2012/PJ_03/um/35645631/36329818/Zaimki_MOJ.pdf).
