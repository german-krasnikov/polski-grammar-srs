# AI: решения и архитектура

Короткая точка входа для людей и агентов. Подробности — в `Plans/Kotlin/`, здесь только то, что нужно знать до начала работы.

| Файл | О чём |
| --- | --- |
| [vision.md](vision.md) | Цель продукта: универсальное ядро для любых языков, а не только польский |
| [architecture.md](architecture.md) | Текущая архитектура хостов и ядра, целевая модульная схема |
| [decisions.md](decisions.md) | Журнал принятых решений (ADR) с датой и причиной |
| [process.md](process.md) | Как работаем: роли, маленькие задачи, параллельные потоки, окружение |

Порядок чтения: `vision` → `decisions` → `architecture` → `process`.

При новом решении добавь запись в `decisions.md` (новые сверху) и, если меняется структура, обнови `architecture.md`. Отменённое решение не удаляй — пометь «заменено ADR-NN».
