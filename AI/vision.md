# Видение продукта

## Цель

Не «выучить польский», а **универсальное ядро изучения языков** — как курс «Полиглот» (Д. Петров): один общий костяк для всех языков. Польский для русскоязычного (`pl-ru`) — первый пакет.

Адаптация идёт по трём независимым осям:

1. **Изучаемый язык** — формы, шаблоны, лексика (данные пакета).
2. **Родной язык ученика (L1)** — опора на знакомое: «в родном так → в изучаемом так, здесь отличается».
3. **Стиль подачи** — предпочтение, а не «тип мозга».

Пример: автор учит польский, говорит по-русски, предпочитает схемы → правило-схема + русская параллель.

## Костяк

Смысловые оси общие для всех языков, различается способ выражения. Таблица Петрова (время × утверждение/вопрос/отрицание × лицо) — частный случай схемы «конструкция × набор признаков».

| Структура | Ось |
| --- | --- |
| `core.argument.case-role` | падеж / роль (предлог, порядок слов) |
| `core.verb.tense` | время |
| `core.sentence.polarity` | отрицание |
| `core.sentence.mood` | вопрос |
| `core.agreement.possessive` | притяжание / согласование |
| `core.number` | число |
| `core.composite` | цепочка из нескольких осей |

## Четыре стиля подачи

| Стиль | Что первым на экране |
| --- | --- |
| Через правило | таблица и схема окончаний, затем пример |
| Через ситуацию | короткая сцена, правило после ответа |
| Через сравнение с родным | параллель L1 → изучаемый, подсветка расхождений |
| Минимум теории | только примеры, «Почему так?» по запросу |

Задания, FSRS и оценки одинаковы во всех стилях. Подгонка обучения под «стиль» не доказана (Pashler et al., 2008), поэтому стиль — только предпочтение подачи. Доказанное для всех: активное вспоминание, интервалы, правило + пример, контраст с L1, чередование.

## Объём сейчас и потом

- **Сейчас:** статичные данные, грамматический костяк, карточки слов.
- **Потом (только точки расширения, не строить заранее):** озвучка (записи/TTS), голосовой ввод, ИИ (объяснения, примеры, диалоги, подсказки).

Главное требование к архитектуре — **гибкая расширяемость**: новый язык, L1, пара, стиль, тип упражнения добавляются данными или новым модулем без правки существующих.
