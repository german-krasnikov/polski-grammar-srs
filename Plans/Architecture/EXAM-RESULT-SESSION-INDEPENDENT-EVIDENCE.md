Timed examples cover start idempotence, prestart, stale module before deadline, deadline equality, matching finish, tick, completion and backward-clock fact. The developer's temporary pending-inversion and stale-guard-removal controls caused four JS test failures before the original policy was regenerated; this verifies the existing authored cases discriminate those two wrong policies.
