# Native iPad grammar exam: first consumer evidence

Date: 2026-11-08. Accepted design: `EXAM-DSL-LOGIC-CORRECTION-PLAN.md`, iPad section. Implementation lives in the shared P11 worktree and is pending independent tester/reviewer gates.

## Scope and ownership

- `kotlin/shared/src/commonMain/kotlin/polski/exam/ExamSourceData.kt`: the existing six official typed grammar mappings moved from `webMain`; bank token IDs, ordered options, instructions, question targets, quarter points, grading modes and conditional variants are preserved. `webMain/ExamData.kt` retains only the historical `b1-sample` alias; the web catalog now derives official entries from shared `ExamCatalog.kt`.
- `ExamCatalog.kt` reads all six currently generated `ExamRow` and `ExamModuleRow` packages, checks route/source reference and module/grammar-cover consistency, and exposes official entries. There is no runtime six-paper limit; a new generated package needs an explicit registry addition. The sample alias is excluded.
- `kotlin/apple-bridge/src/iosMain/kotlin/polski/ios/IosExamSession.kt`: scene-owned bridge around shared `GrammarExamState`, reducer and scorer. It gives Swift JSON snapshots and semantic actions. Pre-submit snapshots omit official answers; submission uses the same Policy-backed evaluator as the web. A tab switch keeps drafts; explicit `exitGrammar`/`close` or selecting a new exam releases them. Word-bank selection retains token identity even for repeated visible text.
- `kotlin/iosApp/PolskiGrammar/NativeExamView.swift` and narrow `PolskiGrammarApp.swift`/Xcode project wiring: catalog of six source papers, four source modules with three clearly unavailable on iPad, and real complete grammar controls/result review. The Exam tab is host-local navigation, not a new training-domain `AppTab`. No Swift scorer or answer-key table. Four new native control labels are authored in both `uiCopy.core-data` packs and its oracle; `UiCopy.kt` exposes them. Audio/images/full timed exam remain outside this first grammar slice.
