# P12: pack-aware UI copy для Swift из DSL

Дата: 2026-11-08. Исполнимое дополнение к [NEXT-SESSION-P9-P12-PLAN.md](NEXT-SESSION-P9-P12-PLAN.md) §P12. `SnapshotCommon.kt` теперь находится в `kotlin/apple-bridge/src/commonMain/kotlin/polski/presentation/` после P5; framework и iOS/macOS Swift build прошли соответствующий P5 gate. Ниже только источник UI-строк и iOS-потребитель; замороженный Desktop не получает новые функции. Исходники/тесты архитектор не менял.

## Подтверждённая граница

`kotlin/shared/src/commonMain/kotlin/polski/presentation/UiCopy.kt` читает `packRegistry.active.uiCopy` и содержит около 40 именованных getters. `PlRuTypedPack.kt:72` и `EnRuTypedPack.kt:73` вручную держат два map с одинаковыми ключами, но разными строками. Apple `SnapshotCommon.kt:85–91` публикует только семь полей `uiResetProgress`, `uiProgressTab`, `uiSettingsTab`, `uiLifehacks`, `uiAgain`, `uiGood`, `uiShowAnswer`; `kotlin/iosApp/PolskiGrammar/PolskiGrammarApp.swift:8` читает top-level `state[key]` с fallback. В `PolskiGrammarApp.swift` и `FlashCardView.swift` ещё десятки видимых русских labels. Значения `tag`, action IDs, `accessibilityIdentifier` и persisted preference enum остаются стабильными строками, переводится только текст.

## Канонический источник и Swift wire contract

В существующий `dsl/course.data-contract` добавить `RECORD UiCopyRow KEY key COUNT 1..` с `key: string`, `text: string`. **NEW** `courses-biome/pl-ru/uiCopy.core-data` и `courses-biome/en-ru/uiCopy.core-data`: перенести **все** нынешние entries из обоих typed maps без изменения ключей/значений, затем авторить новые семантические labels. Два новых `GENERATE` шага в `dsl/biome.project` печатают отдельные `UiCopyRows.kt` в `kotlin/shared/src/commonMain/generated/kotlin/polski/data/rows/{plru,enru}/`; два существующих `fmt` шага включают новые файлы. Это изменение `dsl/biome.project` согласовать с P6/P7 worker, который сейчас им владеет. Рукописный короткий mapper **NEW** `kotlin/shared/src/commonMain/kotlin/polski/data/UiCopyRows.kt` строит map из typed rows, проверяя уникальность/непустоту; `PlRuTypedPack.uiCopy` и `EnRuTypedPack.uiCopy` получают его из своих generated rows вместо ручных maps. Переводы en-ru авторятся как отдельные данные, не копируются механически из pl-ru. Текущие getters и вызовы web/Android остаются; `UiCopy` добавляет только один read-only `all(): Map<String,String>` для bridge, возвращая снимок активного пакета. Swift не импортирует generated Kotlin rows.

Apple `SnapshotCommon.putSharedSnapshotHeader` добавляет **одно** вложенное поле `uiCopy: JsonObject` из `UiCopy.all()`; семь прежних top-level `ui*` полей и их значения сохраняются byte-for-byte для старых потребителей. В `PolskiGrammarApp.swift` локальный `uiText(state,key,fallback)` сначала читает `state["uiCopy"]` и ключ без префикса, затем прежнее top-level поле, затем fallback; новые вызовы используют семантический DSL key. Для существующих вызовов можно передать прежний `uiProgressTab` и сопоставить его с `progressTab` внутри helper, либо оставить семь вызовов на top-level и добавить отдельный `uiCopyText` для новых — выбрать вариант с меньшим Swift diff, но не менять JSON names и не делать второй Swift-словарь. При смене активного pack следующий snapshot полностью пересоздаёт `uiCopy`, без кеша в Swift. `UiCopy.all()` — единственный новый Kotlin public method; проверить Objective-C header, Swift импорт продолжает использовать JSON String snapshot, а не map API.

Первый вертикальный срез — navigation + reset alert + answer mode + `FlashCardView` reveal/rating. После него применить группы settings, progress, vocabulary; для matrix content провести отдельный source audit. Динамические подписи вроде `Следующее: <дата>` и `Повторений: <число> ...` авторить как шаблоны с именованными `{date}`/`{reviews}`/`{correct}`/`{streak}` только для реально используемых строк. Swift делает механическую подстановку с проверкой отсутствия неизвестного placeholder; формат даты/числа остаётся у native host. Не создавать общий expression engine или хранить готовые строки с данными пользователя в DSL.

## Независимая приёмка

**NEW** `dsl/ui-copy/uicopy-oracle.core-data` и малый `UiCopyCaseRow` в `dsl/course.data-contract` фиксируют `key`, ожидаемое pl-ru/en-ru значение для репрезентативных keys всех групп и placeholder names. Shared commonTest сверяет полное равенство множеств ключей обоих пакетов, непустые значения, неизменность прежних keys и отдельные oracle examples при переключении pack; отсутствующий ключ должен падать в gate, не превращаться в видимое имя свойства. Apple `iosTest` проверяет старые семь top-level полей + новое `uiCopy`, pl-ru→en-ru→pl-ru, типы значений, template placeholder и отсутствие кеширования. Тестовые ожидания авторятся независимо от generated pack rows; не вычислять expected из production `UiCopy.all()`.

`kotlin/iosApp/PolskiGrammarUITests/` дополняется сфокусированным simulator сценарием: видимые tab labels, reset alert, answer picker, карточка и Progress/Vocabulary после смены курса; accessibility labels тоже локализованы. Сначала компиляция `:shared:iosSimulatorArm64Test :apple-bridge:iosSimulatorArm64Test`, затем `xcodebuild -project kotlin/iosApp/PolskiGrammar.xcodeproj -scheme PolskiGrammar -configuration Debug -destination 'generic/platform=iOS Simulator' -derivedDataPath kotlin/iosApp/build CODE_SIGNING_ALLOWED=NO build`; для UI tests выбрать установленный destination через `xcodebuild -showdestinations ...` и выполнить `xcodebuild test` на нём. Generic destination доказывает build, но не UI runtime; physical device/VoiceOver отдельно PASS/FAIL/NOT RUN. `biome fmt` обоих новых файлов, `biome generate`, `biome generate --check --project dsl/biome.project`, затронутые JS/Wasm/Android compile gates после изменения pack map. Reviewer сверяет отсутствие потери старых JSON keys, смену пакета, стабильность action IDs и отсутствие новых Desktop features. P25: десятки pack-aware меток и oracle имеют высокий V1/V3, DSL снимает две ручные map (~100 entries); механическая snapshot/Swift render остаётся native, без построчной транслитерации в DSL PROGRAM.
