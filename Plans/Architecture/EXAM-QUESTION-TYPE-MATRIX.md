## Proven gaps and minimal next edits

1. **Wrong binary controls in B1/2020:** Reading II paper/source requires TAK/NIE, but seven rows omit `options`; `ExamReadingWeb` invents a third `BRAK INFORMACJI`. Listening III has five missing `options` rows with TAK/NIE keys while `ExamListeningWeb` defaults to PRAWDA/FAŁSZ, making all five impossible to score. B1/2017 Listening IV intentionally omits options and uses the latter labels. Add explicit `options: "TAK|NIE"` to the twelve B1/2020 source rows, regenerate, and assert actual buttons and scored responses in browser DSL. The independent tester reproduced both RED cases on the frozen six-exam artifact; every other binary group in these papers either supplies options or is that B1/2017 fallback.
2. **Bank controls:** B1/2019 II/VIII and B2/2017–2020 II currently require typing despite printed banks; B1/2017 VI and B1/2020 II/VIII show per-item option buttons. A source-backed selectable bank needs one canonical bank per task (with duplicate occurrences where printed), typed selection payload, and the already accepted II/6→II/8 conditional scoring. Do not parse bank words from prose at runtime or invent global depletion rules.
3. **Semantic tags and explicit rendering:** The six papers contain question formation, word formation, fragment gaps and matching, but their rows reuse broad tags (`fill_gap`, `transform`, `match_heading`, `match`). Add only the required tags/forms after confirming each source row's paper role. Current mapper throws for unknown tags; web generic `else` branches can silently yield zero controls when `options` is absent, so add exhaustive control handling and negative tests.
4. **Session boundary:** Grammar has a shared reducer/scorer; reading, listening and writing still keep mutable answer/draft state in web controllers. The accepted P11 plan moves those rules to shared code and only then adds full timed four-part flow. Catalog counts and a successful opening screen do not verify answer preservation, provisional totals or complete session behavior.

After independent browser RED for both B1/2020 binary defects on the frozen `87e91a17…` artifact, the twelve `.core-data` rows in item 1 received explicit `TAK|NIE` options. `biome fmt`, `biome generate`, and `biome generate --check` passed; browser GREEN requires the next distribution and is recorded separately. The smallest remaining P10 production slice is a task-level bank source/control, followed by explicit question-formation, derived-word and fragment/matching tags with focused payload tests. The current correct strings, item IDs and scorer policy remain authoritative during those additive edits.
