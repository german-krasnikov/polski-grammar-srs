## 1. Аудио: воспроизводимый локальный artifact

Факт: `kotlin/composeApp/src/webMain/resources/exam-audio/.gitignore` исключает `*.mp3`; локально лежат B1-2017 (23 580 465 байт), B1-2019 (61 933 236) и B2-2019 (83 110 182), но `git ls-files` видит только `.gitignore`. `ExamBin/pl/{B1,B2}/{2017,2019,2020}/audio.mp3` есть локально, в checkout не попадает. Текущий чистый build поэтому может скомпилироваться с отсутствующим аудио. Уже принятый [EXAM-AUDIO-PLAYBACK-PLAN.md](EXAM-AUDIO-PLAYBACK-PLAN.md) запрещает считать публикацию копий официальных MP3 автоматически разрешённой.

На [официальной странице экзаменов](https://certyfikatpolski.pl/o-egzaminie/przykladowe-testy-zbiory-zadan/) находятся ссылки MP3 для всех шести сдач. Точные адреса: B1-2017 `https://certyfikatpolski.pl/wp-content/uploads/2017/03/Egzamin-Przyk%C5%82adowy-B1-gru2016.mp3`, B1-2019 `https://certyfikatpolski.pl/wp-content/uploads/2019/09/B1_audio.mp3`, B1-2020 `https://certyfikatpolski.pl/wp-content/uploads/2020/12/B1_2020_03.mp3`, B2-2017 `https://certyfikatpolski.pl/wp-content/uploads/2017/03/Egzamin-przyk%C5%82adowy-B2-listopad-2016-poprawiony.mp3`, B2-2019 `https://certyfikatpolski.pl/wp-content/uploads/2019/09/B2_audio.mp3`, B2-2020 `https://certyfikatpolski.pl/wp-content/uploads/2020/12/B2_03_2020.mp3`. В текущей среде `curl -I -L` на все шесть и `curl --range 0-1` на B1-2017 дали HTTP 403; наличие ссылки не доказывает, что CLI или production browser может скачать файл. **Автозагрузка из этих URL пока не проходит критерий свежего checkout.**

Минимальный DSL источник — `dsl/exam-assets.data-contract` **NEW** с `ExamAudioAssetRow KEY examId` (`examId`, `officialDownloadUrl`, `sha256`, `webPath`, `localSourcePath` — строки). `dsl/exam-assets/exam-audio.core-data` **NEW** содержит шесть записей, независимые от UI; `GENERATE exam-audio-assets data ... --target ts --out dsl/exam-assets/generated/ExamAudioRows.ts` в `dsl/biome.project` поддерживается существующим `data` TS printer (пример в biome-dsl corpus/labs/data-print). Для локальных файлов уже измерены SHA-256: B1-2017 `e7d78c0f1bf64ef6ebf83e7d8b9d38f30539a2d33f205d40d230d56d03fb2747`; B1-2019 `55a563e5a53cb6f576e565fd4656fd705074cf25073a75804afeb19e3159ede1`; B1-2020 `b88f61dea88036425bfd6990c07f308264a42b06d0aa9ce75a64a82bf3e840c8`; B2-2017 `d1d865a43dd4a6e91ef2508e1476cdffca2413e0abcd25a9371b568b702cf84e`; B2-2019 `4aa580740d38b5f5a3cbcd10c0b6b4e9ed700d6c1407dce60c2733445d9b9650`; B2-2020 `e931d9c4466ee5186a6b47fb3a01201a93882791c8bbc74a2ea8275ba9f3d72e`. Эти hash закрепляют локальные полученные байты; равенство скачанным официальным URL ещё надо проверить полным GET.

Нативный `scripts/prepare-exam-audio.ts` **NEW** (через существующий `tsx`) читает только сгенерированные rows: для каждой объявленной в web каталоге сдачи берёт локальный `ExamBin` файл, либо пробует официальный URL; сверяет SHA-256 и копирует в `kotlin/composeApp/src/webMain/resources/exam-audio/<B1-2017>.mp3` до Gradle distribution. При недоступности/неверном hash завершается с ошибкой и не оставляет частичный файл. Проверка artifact после сборки удостоверяет наличие всех объявленных URL и байтов, не только исходников. `audioUrl` в `listening-tasks.core-data` — webPath из того же manifest; тест соответствия предотвращает два источника имени. Build/CI должны явно вызывать prepare и gate; простая сборка без gate не доказывает наличие аудио. Не обходить 403 фиктивным файлом или молчаливым fallback. Если требуется именно самодостаточный fresh checkout без доступа к официальному URL, этот критерий остаётся заблокированным до разрешённого versioned binary/доступного mirror; добавить MP3 в Git только после решения о правах и профиле распространения. Публикация отдельно.

Измерение P25: шестистрочный asset manifest объединяет URL/hash/path для prepare, validation и artifact check (V1/V3); механические SHA/download/copy — native (S5). Не создавать DSL PROGRAM для fetch или нового asset pack ради шести строк.

## 2. B1/2020 Listening IV: набор из двух ответов

В `exams/pl/certyfikat-polski/B1/2020/listening-questions.core-data` IV/B и IV/C сейчас `questionType: match`, `options: "1|2|3|4"`, `correctAnswer: "1|4"` и `"2|4"`, `pointsQuarter: 8`. Текущий `ExamListeningWeb.kt` рисует один выбор и сравнивает строку, поэтому полный правильный ответ недостижим. Добавить к `ListeningQuestionRow` `answerMode: enum single|unordered_set OPTIONAL` (default `single`) и, **только если официальный ключ подтверждает начисление за каждую из двух позиций отдельно**, `creditPerCorrectQuarter: int OPTIONAL` (для этих строк 4). Значение `pointsQuarter: 8` — максимум, `correctAnswer` — канонический набор без порядка; `|` в single mode остаётся буквальной частью ответа, не скрытым признаком новой политики.

Mapper `ExamListeningData.kt` переносит mode/credit в `ListeningQ`; `ExamListeningWeb.kt` для unordered_set рисует переключаемые варианты с ограничением числа выбранных вариантов размером ключа. Один вопрос сохраняется как набор distinct tokens, не как случайная строка порядка кликов. Чистый scorer возвращает integer quarter units: полный правильный набор 8; один правильный выбор даёт 4 **только при подтверждённом per-slot ключе**; лишний, повторный или неизвестный вариант не создаёт кредита. Правило при сочетании правильного и неправильного выбора надо зафиксировать по официальной инструкции/ключу до реализации, а не угадать. Если ключ не даёт частичной оценки, использовать exact-set 8/0 и не задавать `creditPerCorrectQuarter`. UI показывает баллы `formatQuarterPoints`, review отображает оба эталонных номера. В `dsl/exam-scoring/weighted-scoring.core-data` или отдельном record добавить независимые oracle-кейсы: оба порядка полного набора, одиночный правильный, неверный, дубликат, лишний, пустой; не генерировать expected из scorer.

Для True/False сохранять дословные `PRAWDA`/`FAŁSZ` или `TAK`/`NIE` в `correctAnswer` и явном `options` соответствующего задания. Рендер читает `options` из DSL; нормализатор может сравнивать только подтверждённые эквиваленты, не переводить `PRAWDA` в `TAK` по умолчанию. Дефолтные `TAK/NIE` у текущих контроллеров не применяются к заданию с другим словарём.
