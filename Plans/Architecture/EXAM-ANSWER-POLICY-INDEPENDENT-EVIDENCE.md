Both use the existing `AnswerEvaluationCaseRow` contract. The existing generated scorer oracle and `ExamAnswerEvaluationTest` will consume them after the developer adds the file to the Biome step; the frozen rows are untouched. These two API examples complement the nine Logic fact vectors and keep expected status and quarter values in DSL.
