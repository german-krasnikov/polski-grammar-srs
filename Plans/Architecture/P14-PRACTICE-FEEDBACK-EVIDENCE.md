# P14 first slice — practice feedback evidence (2026-11-13)

Scope: shared practice choice policy/state and portable preference; standalone Web grammar `ChooseForm`. Reading, listening, word bank, text input, native consumers and the later P15 review projection remain outside this slice. Timed exam keeps the existing editable reducer and no early answer key.

## Implementation

- `dsl/exam/practice-feedback-policy.{logic,contract,examples}` owns the practice commit/feedback/advance decision from mode, preference, first-answer, dependency, existing scorer status and source position facts. `biome generate` prints its Kotlin adapter.
- `ExamPracticeFeedback` retains the first raw choice, uses `GrammarExamScorer.gradeInAttempt` against the full attempt answer snapshot and emits a generation-tagged view. The Web controller owns the 2000 ms timer and cancels it on navigation, submit, reset, visibility change and close.
- The preference defaults on when absent in legacy JSON or POLSKI-TEXT; explicit false persists in schema 3. Web settings can disable it. Authored pack UI copy supplies answer and status labels. The grammar result names the chosen answer explicitly without changing scoring.
