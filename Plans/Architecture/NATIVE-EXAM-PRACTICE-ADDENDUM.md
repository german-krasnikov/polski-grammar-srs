## Текущие потребители и границы

`IosExamSession` — scene-owned Kotlin session; `answerInModule`, `answerBankTokenAt`, `nextInModule`, `previousInModule`, `submitInModule`, `currentSnapshot` уже экспортированы Swift. Standalone Reading/Listening/Grammar reducers владеют answers, timed `ExamSessionState` владеет deadline/frozen results. Сегодня `grammarReviewItemJson` пересчитывает grade, а `readingJson`/`listeningJson` кладут status/examples в question лишь после Submit; Swift `NativeExamView.questionControl` показывает status, но grammar result показывает `answer` без отдельной подписи выбранного. `NativeExamModel` владеет `IosExamSession`, `setSlotDrafts` и `ExamSegmentPlayer`; `NativeExamView` монтируется из `PolskiGrammarApp` как Exam tab. `IosPreferencesSession` пишет `polski-preferences-v2` в `NSUserDefaults`, его snapshot ещё не выдаёт portable `immediateExamFeedbackEnabled`, хотя общий codec уже имеет default `true`. Настройки — sheet в `PolskiGrammarApp.swift`, значит смена флага может произойти при живом экзамене.

## Bridge API и снимок (NEW)

| Владелец | Узкий контракт |
|---|---|
| `kotlin/apple-bridge/src/iosMain/kotlin/polski/ios/IosPreferencesSession.kt` | `currentSnapshot()` добавляет boolean `immediateExamFeedbackEnabled`; `set("immediateExamFeedbackEnabled", "true"/"false")` использует `toBooleanStrictOrNull` и текущий codec/write. Отсутствие старого поля → true, явное false экспортируется/импортируется и переживает restart; `RecoveryRequired` и raw backup остаются нетронуты. |
| `kotlin/apple-bridge/src/iosMain/kotlin/polski/ios/IosExamSession.kt` | Добавить session-owned `practiceByModule: Map<ExamModule, PracticeFeedbackState>` для standalone Grammar/Reading/Listening, `immediateFeedbackEnabled` и `setImmediateFeedbackEnabled(Boolean)`. В `answerInModule` для выбора вызвать `acceptGrammarPracticeInput` / `acceptReadingPracticeInput` / `acceptListeningPracticeInput` с **текущим group ID** и reducer answers; новый committed answer dispatch `Answer` ровно раз. Для typed/open `answerInModule` остаётся draft; `checkPracticeAnswerInModule(module, itemId, nowEpochMs)` фиксирует текущий draft через `PracticeInputEvent.Check`. `answerBankTokenAt` передаёт исходный token ID общему helper. Timed/writing идут по существующему пути, без раннего key или auto-grade. Ошибки `unknown_item`/`stale_module` применяются и к Check; не принимать ответ чужой группы. |
| Тот же bridge | `advancePracticeFocusInModule(module, groupId, itemId, generation, nowEpochMs)` — атомарное действие по живому session snapshot: проверяет practice ON, standalone, current module/group/item, visible generation, `mayAutoAdvance`, not submitted. Grammar пользуется `advancePracticeFocus` и reducer `Next` до target; grouped Reading/Listening — `advanceGroupedPracticeFocus` только внутри текущего passage/task, без reducer `Next`. Неверный/устаревший token — no-op. `clearPracticeFeedbackInModule(module)` скрывает transient verdict и повышает generation, **сохраняя committed**. `next/previous/submit/selectExam/selectModule/startTimed/exitGrammar/close` также инвалидируют transient state до смены context; новая попытка после submit создаёт новый practice state. |
| `currentSnapshot()` | На `grammar` и `part` добавить `practice` объект `{enabled, generation, focusedQuestionId, visible}`; `visible` либо null, либо `{itemId, chosen, officialExamples, status, confirmedQuarter, pendingQuarter, maximumQuarter, mayAutoAdvance, generation}` из shared `FeedbackView`/evaluation. Grammar card получает `{committed, committedRaw, committedTokenId}`; Reading/Listening каждая question row те же first two поля. Эти поля появляются **только** в practice snapshot, не превращают timed answer key в доступный. `committed` и neutral selected raw берутся из `PracticeFeedbackState.committed`, независимо от `visible`: после Back/background lock остаётся, verdict/timer исчезает. В submitted snapshot `practice.visible=null`; review поля от frozen answers. |
| `ExamReviewRow.kt` → bridge | Для grammar `grammarReviewRows`, Reading `readingReviewRows`, Listening `listeningReviewRows` проецируются в единый JSON row `{itemId, chosenAnswer|null, officialExamples, status, confirmedQuarter, pendingQuarter, maximumQuarter}`; context/questionText — отдельное source поле. Grammar rubricComponents остаются дополнительным полем. Reading/Listening standalone result получает `review` всех source rows, не только текущей карточки. После завершения timed sitting те же frozen part answers в `ExamSessionState.{grammar,reading,listening}` + `frozenResults` дают review каждой завершённой части; до `FinishPart`/deadline соответствующий ключ не выдаётся. Никакого повторного scorer в Swift, `PendingManual` и Writing draft/rubric остаются ручной оценкой. |

Существующий `ExamReviewRow` не содержит `context` и `maximumQuarter` по группам, поэтому bridge присоединяет presentation source text по `itemId` в source order, не меняя score. Поле `visible.maximumQuarter` можно получить от текущего source item/question при сериализации; оно не policy. Исходные `answers` до Submit могут содержать черновики; committed lock всегда выводится из `practiceByModule`, а финальный `chosenAnswer` только из submitted frozen maps. Не сохранять transient practice state в FSRS/progress.

## Preference во время попытки и ресурсы

`PolskiGrammarApp.swift` передаёт `model.preferences.bool("immediateExamFeedbackEnabled", default: true)` в `NativeExamView`/`NativeExamModel` при первом показе и при `onChange` snapshot после Settings `set` **и** import; не кэшировать флаг в `NativeExamView.init`. В `IosSettingsView` добавить `Toggle` с pack `uiText(..., "examImmediateFeedbackSetting")`, `accessibilityIdentifier("settingsExamImmediateFeedback")`; портативный codec сохраняет только флаг. Swift передаёт изменение в `IosExamSession.setImmediateFeedbackEnabled` немедленно, даже если Settings sheet скрывает Exam view.

При реальном ON↔OFF переключении внутри standalone попытки session **очищает `practiceByModule` committed/evaluations/visible и увеличивает generation**, но не сбрасывает reducer answers, currentIndex, drafts, source test или submitted result. Это намеренный выход из режима «первый ответ заблокирован» без скрытого reset попытки: OFF позволяет редактировать текущие ответы; возврат ON рассматривает существующие reducer answers как редактируемые drafts до следующего явного Choice/Check, старые locks не возрождаются. Swift сразу отменяет Task и перерисовывает controls по новому snapshot, поэтому не остаётся выглядящей активной, но игнорируемой кнопки. После submitted switch меняет только будущие попытки; frozen review не пересчитывать. При `RecoveryRequired` не перезаписывать raw и не создавать пустую настройку; текущий session mode остаётся последним успешно применённым до восстановления.

`NativeExamModel` владеет одним `Task<Void, Never>?` для 2000 мс, токеном `(module, groupId, itemId, generation)` из snapshot и отменой в `deinit`, `next/previous/submit/selectExam/selectModule/startTimed/exitGrammar/close`, preference change, tab disappearance и scene inactive/background. `NativeExamView` следит за `scenePhase`/onDisappear и вызывает model cancellation/`clearPracticeFeedbackInModule`; `Task.sleep` — только scheduler, не решение о grade/target. После sleep повторно сверить snapshot/token и вызвать атомарный bridge advance. После foreground таймер сам не возобновляется; ранее committed answer показывается нейтрально. `@FocusState`/`ScrollViewReader` переводят доступный фокус к `focusedQuestionId` внутри той же группы; на последнем вопросе нет timer. `ExamSegmentPlayer` остаётся тем же объектом на same-task answer/grade/focus и не получает `stop`, `seek` или `replay`; `next/previous` вручную меняют task и могут остановить сегмент, как сейчас. Tab/background может `pause` согласно существующему lifecycle, сохраняя позицию. Отображение feedback не зависит от Rive/CSS/animation completion; Reduce Motion отключает эффект, не двухсекундное правило.

Swift controls выводят красный выбранный и зелёный официальный вариант **плюс** текст/символ/VoiceOver value; `PendingManual` — нейтральное «Требует проверки», `ConfirmedPartial` — реальные quarter points и при необходимости pending. Locked answer управляется `committed`, а не `visible`; повторный tap не меняет first raw/token. Для text/open set «Проверить» доступно после заполнения слотов; при OFF/timed обычное свободное редактирование и Submit. Выбранный неправильный и официальный ответы в review имеют отдельные pack labels `examYourAnswer`/`examOfficialExamples`; blank — `noAnswerEntered`. Dynamic Type, light/dark/Increase Contrast и VoiceOver проверяются на настоящем SwiftUI screen.
