# P18 slice A: `degree.comparison`

2026-11-13. Implementation evidence for the first comparison skill only. This adds one B1 introductory skill; it does not claim complete B1/B2 comparison coverage or close P18/P19.

## Source chain

- Need: [`certyfikat-polski-B1-2017-grammar-2`](../../exams/pl/certyfikat-polski/B1/2017/grammar-tests.core-data) and [`certyfikat-polski-B2-2017-grammar-8`](../../exams/pl/certyfikat-polski/B2/2017/grammar-tests.core-data) explicitly name adjective and adverb comparison. This slice trains adjective degrees. Adverb comparison remains outside this skill.
- Grammar: Oscar E. Swan, *A Grammar of Contemporary Polish* (2002), [author PDF](https://lektorek.org/lektorek/grammar.pdf), chapter 6 pp. 143–151, checked 2026-11-13. Pages 143–145 give the simple, irregular, and analytic comparative and `naj-` superlative; p. 151 gives `od + Genitive` for nominal comparison and `niż` for clausal comparison. The six whole sentences below are project-authored applications of those rules, not copied official exam questions.
- Authoring: [`skills.core-data`](../../courses-biome/pl-ru/skills.core-data), [`recipes.core-data`](../../courses-biome/pl-ru/recipes.core-data), [`exerciseCopy.core-data`](../../courses-biome/pl-ru/exerciseCopy.core-data), [`lifehacks.core-data`](../../courses-biome/pl-ru/lifehacks.core-data), and [`reference.core-data`](../../courses-biome/pl-ru/reference.core-data). The `book`/`new` IDs in `StaticExerciseRow` are valid engine metadata slots only; they are not claimed as words in the authored sentences. `caseReferenceAvailable: false` suppresses their unrelated case table.

| Task | Source → requested operation → expected full sentence | Rule checked |
| --- | --- | --- |
| 1 | `Ten dom jest stary.` → simple comparative → `Ten dom jest starszy.` | Swan p. 143: `stary → starszy` |
| 2 | `To zadanie jest łatwe.` → simple comparative with neuter agreement → `To zadanie jest łatwiejsze.` | Swan p. 143: `łatwy → łatwiejszy`; adjective inflection |
| 3 | `Ta książka jest dobra.` → irregular comparative with feminine agreement → `Ta książka jest lepsza.` | Swan p. 144: `dobry → lepszy`; adjective inflection |
| 4 | `Ten film jest interesujący.` → analytic comparative → `Ten film jest bardziej interesujący.` | Swan p. 145 explicitly lists `interesujący → bardziej interesujący` |
| 5 | `To jest duży pokój.` → superlative → `To jest największy pokój.` | Swan pp. 144–145: `duży → większy`, `naj-` superlative |
| 6 | `Ten rower jest szybki.` → comparative with `od` and named second bicycle → `Ten rower jest szybszy od tamtego roweru.` | Swan pp. 144, 151: `szybki → szybszy`, `od + Genitive` |

The prompts constrain the operation, including simple versus analytic formation, without providing the target sentence. There are no additional accepted strings because the prompts request a specific operation. The comparison with `od` deliberately requests that construction; `niż tamten rower` is not an alternative to that requested form. The single Swan-backed tip explains the Russian transfer risk at `od + Genitive`. The Matrix summary uses a separate bridge example, and four authored style blocks use separate examples from the current task.
