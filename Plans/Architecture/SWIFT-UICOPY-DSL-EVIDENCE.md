- Swift `uiText` uses nested copy first, the legacy top-level key second, and the literal preview fallback last. `uiFormat` substitutes named dynamic values and rejects unrecognized/unfilled placeholders. SwiftUI labels, controls, accessibility text, and template text in the named P12 groups read the snapshot; stable action IDs, tags, and accessibility identifiers remain unchanged. `tests/ui-copy-swift-source.test.ts` checks that every statically named Swift key has rows in both packs.
- Matrix instructional prose and English grammar explanations remain course content, not UI copy. `matrix.string(...)` and row-backed text already come from course/snapshot data. A few hardcoded subject explanations in `PolskiGrammarApp.swift` (the English do-support and generated-forms descriptions) have no existing corresponding en-ru reference row; this P12 UI-label change does not silently classify them as UI labels.
