Дата: 2026-11-08. Узкое дополнение к [EXAM-OPEN-ANSWER-ADDENDUM.md](EXAM-OPEN-ANSWER-ADDENDUM.md), без замены принятой модели оценки.

## Проверенный источник и текущее поведение

`ExamBin/pl/B2/2020/arkusz.pdf`, с. 19: Grammar II содержит рамку `dla dzięki na na o od do przy u w wokół wbrew za`, каждое **вхождение** слова используется не более раза; пример уже расходует первое `na`, II/1 использует второе. `ExamBin/pl/B2/2020/klucz.pdf`, с. 7: II/6 = `w`, II/8 = `przy / w (jeżeli nie został wykorzystany w p. 6)`. Это условие относится к ответу II/8, а не к любому употреблению слова `w` в тексте. Источник `exams/pl/certyfikat-polski/B2/2020/grammar-items.core-data` сейчас содержит II/6 `correctAnswer: w`, II/8 `correctAnswer: przy`, по 2 четверти; тест `grammar-2` в `grammar-tests.core-data` воспроизводит рамку. Добавлять `w` как безусловный scored variant для II/8 нельзя.

## Минимальный DSL контракт

К существующему `GrammarAnswerVariantRow` в `dsl/exam.data-contract` добавить одно `onlyIfNotUsedBy: ref GrammarItemRow OPTIONAL`. Семантика: variant допустим, только если нормализованный ответ на указанный **другой** item не равен нормализованному `variant.answer`. Отсутствие поля сохраняет прежний безусловный вариант. В новом `exams/pl/certyfikat-polski/B2/2020/grammar-answer-variants.core-data` записать II/8 `answer: w`, `earnedQuarter: 2`, `onlyIfNotUsedBy: certyfikat-polski-B2-2020-grammar-2-6`; II/8 `correctAnswer: przy` остаётся полным безусловным ответом. `dsl/biome.project` B2/2020 `GENERATE` включает `--rows GrammarAnswerVariantRow` для этого файла; generated Kotlin только через biome. Валидация после row mapping: ссылка указывает на другой item того же test, variant не дублирует canonical/другой normalized answer, 0 < earnedQuarter ≤ item maximum. Не вводить общую модель склада слов для одного условного ключа; печатная рамка остаётся в `GrammarTestRow.instruction` и не переписывается вторым словарём.

## Потребители и ownership

`kotlin/shared/src/commonMain/kotlin/polski/exam/grammar/GrammarExamModel.kt`: расширить `GrammarScoredVariant` optional `onlyIfNotUsedByItemId: String? = null`, сохранив старые конструкторы/2019. `kotlin/composeApp/src/webMain/kotlin/polski/ui/ExamData.kt` передаёт поле из generated variant. `GrammarExamScorer.grade(item, answer)`/`earnedQuarter(item, answer)` и `score(item, answer)` — существующие context-free API; `score` продолжает проверять canonical full answer, а context-free `grade` **не может** подтверждать условный variant без ответов на другие пункты и не должен выдавать за него баллы. Добавить `gradeInAttempt(test, item, answers)` (или эквивалентный внутренний helper), который применяет условие к карте ответов и передаёт в существующий `evaluateExamAnswer` только допустимые variants. `scoreAttempt` суммирует именно context-aware оценки; общий `ExamAnswerEvaluation` и pending/manual policy из предыдущего дополнения остаются единственными типами статуса. У II/8 `gradingMode=exact`: если `w` заблокирован, результат wrong, не pending.

`GrammarExamSession.kt` уже владеет `answers` и фиксирует их при Submit; `GrammarExamCardModel.kt` и `ExamGrammarWeb.kt` для review используют context-aware grade с той же картой, чтобы результат и строка ответа не противоречили друг другу. Оценка вычисляется из **полного снимка** ответов и не зависит от порядка ввода/обхода items. При исправлении II/6 до Submit II/8 переоценивается из текущего снимка, без мутации набранного II/8 текста; review после Submit отражает последнюю карту ответов. После Submit источник ответов неизменен. Индивидуальные пункты других тестов продолжают оцениваться как прежде. Нельзя делать глобальное правило «любой повтор в рамке = ошибка» без отдельного подтверждения официальной политики; здесь доказано ровно условие II/6→II/8.
