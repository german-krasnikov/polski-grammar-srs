## Текущее состояние инвентаризации

Генератор scripts/inventory-course.mjs рекурсивно проверяет 101 production-файл React/TS, Kotlin и SwiftUI. После партии 6 свежий source-inventory содержит 2365 строк-кандидатов, а checker разворачивает их в 4504 token/JSX-text частей с явным решением. Это не число учебных литералов: туда входят imports, JSON/DOM keys, ошибки, ID, кнопки и форматирование. В course.json теперь также находятся matrix/context/Biernik/aspect help, четыре host-варианта CEFR-инструкции, unavailable-label и учебный заголовок состава словосочетания для Kotlin Web. Критерий завершения — проверенная редакторская классификация и паритет, а не ноль строк.

Учебные данные — фиксированные польские формы, русские объяснения польской грамматики, демонстрационные фразы, выбранный порядок справочных рядов и подписи учебной цепочки. UI chrome — навигация, ввод, rating, действия, доступность, хранение и сообщения ошибок. Runtime — ID, enum, правила выбора окончаний, сборка предложения и диагностика. Переносить только первую категорию; остальные явно классифицировать.

## Что остаётся в коде по назначению

- src/training/generator.ts и Kotlin ExerciseFactory.kt: skill IDs, tags, ограничения seed, random/ID, сборка expected и error paths — поведение. Уже извлечённые exerciseCopy/patterns не дублировать.
- src/grammar/engine.ts и Kotlin GrammarEngine.kt: выбор падежа/времени, suffix rules, Unicode/spacing, диагностические сообщения — алгоритм. Табличные формы отдельно рассматривает партия 5.
- App.tsx, TrainingWebApp.kt, VocabularyView.tsx, VocabularyWeb.kt, native TrainingScreen/AndroidTrainingScreen/SwiftUI: tab/button names, keyboard hints, labels для ввода, aria/accessibility, reset/export/import, storage failures, durations, persistence keys и filenames — UI/runtime. A1/A2/B1 filters, 100/500/1000 slices и ru-pl/pl-ru IDs — state contract, не карточки. Атрибуция частотного источника принадлежит metadata/ATTRIBUTION.md; хост лишь показывает ссылку.
- CourseData.kt, IosSnapshot.kt, adapters: JSON keys, schema checks, DOM/Compose/Swift plumbing и lang=pl — сериализация/представление. ReferenceChainComparison.kt рендерит «Было/Стало»; польские пары уже приходят из pack.

## Общий метод и gate завершения пакета

Для каждого batch: зафиксировать before-output каждого затронутого host; добавить nonblank/noHtml schema и semantic checks на ID/связи; переподключить React/Kotlin adapters и iOS snapshot только при наличии consumer; проверить точные текстовые fixtures, negative validation, browser/native rendering и сгенерировать inventory скриптом. Не улучшать copy внутри extraction diff; редакторское исправление должно быть отдельным явным изменением. Tester независимо проверяет доказательства и NOT RUN, Reviewer читает итоговый diff.

Gate «pl-ru pack complete» для этапов 1–2: все партии 0–6 приняты; каждый оставшийся candidate свежего generated inventory классифицирован как pack-backed authored, runtime morphology, UI localization/chrome, serialization/plumbing или diagnostic с конкретным path/symbol и причиной; пять не подключённых файлов Compose spike имеют отдельную allowlisted категорию `inactive-prototype`. Реализованы courses/pl-ru/inventory-decisions.json и checker новых неклассифицированных учебных групп; generated literalLines не править вручную. Не остаётся польской формы, учебной схемы, демонстрационного предложения или русской грамматической подсказки, которая живёт только в одном UI host. Валидатор и offline load проходят, React/Kotlin pinned grammar/exercise/progress fixtures сохраняются либо изменены отдельным согласованным контрактом, пять host variants проверены по доступным средам. Pack completion не закрывает web parity и device gates [Plan.md](Plan.md); browser/simulator/physical-device evidence записывается раздельно PASS/FAIL/NOT RUN.
