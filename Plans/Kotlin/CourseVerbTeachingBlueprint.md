# Срез course pack: глагольная справка

## Scope и наблюдаемый baseline

Партия 2 [CoursePackRemainingRoadmap.md](CoursePackRemainingRoadmap.md) этапов 1–2 [CoursePacksPlan.md](CoursePacksPlan.md): перенести девять фиксированных субъектов таблицы «Лицо × число × время», подписи трёх времён, варианты выбора рода и учебное пояснение составного будущего в courses/pl-ru/course.json. Грамматические формы остаются результатом verbForm, а reference.tenseRows и reference.aspectRows уже находятся в pack. Эта партия не меняет выбор глагола (только imperfective), состояние feminineGroup, упражнение, FSRS и progress JSON. Партия 1 меняет те же adapter/host файлы; её результат следует принять до реализации этого среза.

Источники: src/ui/GrammarTables.tsx (subjects и verbs section); kotlin/composeApp/src/webMain/kotlin/polski/ui/MatrixWeb.kt (renderVerbs); kotlin/composeApp/src/desktopMain/kotlin/polski/ui/screens/MatrixScreen.kt (VerbsDesktop); kotlin/composeApp/src/androidMain/kotlin/polski/ui/screens/AndroidMatrixScreen.kt (AndroidVerbsSection); kotlin/shared/src/iosMain/kotlin/polski/ios/IosSnapshot.kt (matrixSnapshot/verbsRows); kotlin/iosApp/PolskiGrammar/PolskiGrammarApp.swift (verbs). Все пять хостов сейчас имеют одинаковую последовательность девяти позиций и разное представление: React/Kotlin Web/Desktop — 9×3 таблица, Android/iOS — девять карточек/секций по три формы. ## Контракт авторских данных

Добавить обязательный reference.verbTeaching со следующей узкой структурой:

- subjects: упорядоченные девять объектов с id ja, ty, on, ona, ono, my, wy, oni, one; каждый имеет person (1/2/3), number (sg/pl), genderMode (selected/fixed), fixedGender только для fixed (m-personal/f/n), label.full и label.compact. У восьми позиций значения labels совпадают; у oni они различаются как в baseline выше. Поле selected означает gender = f при feminineGroup=true и m-personal иначе, ровно для ja/ty/my/wy; оно не хранит значение текущего переключателя в pack.
- genderControlLabel.full = «Род для ja / ty / my / wy», compact = «Род». genderOptions в порядке m, f: m.full = «Мужской / мужская личная группа», m.compact = «Мужской»; f.full = «Женский / женская группа», f.compact = «Женский». ID m/f остаются текущими значениями control/action.
- tenseLabels для present/past/future с full «Teraz · сейчас» / «Przeszłość · прошлое» / «Przyszłość · будущее» и compact «Teraz» / «Przeszłość» / «Przyszłość». Порядок Tense.PRESENT, PAST, FUTURE сохраняется в вычислении, не выводится из порядка ключей JSON. Существующие snapshot keys present/past/future не переименовывать.
- futureExplanation.react и futureExplanation.compact с точными предложениями выше. Никаких HTML, вычисляемых шаблонов или дублированных готовых спряжений.

Schema courses/schema/course-pack-v1.schema.json задаёт required, additionalProperties:false, nonblank/noHtml строки, ровно девять subjects и два genderOptions. scripts/validate-course.mjs проверяет ровно указанный порядок уникальных subject IDs, соответствие person/number каждой позиции, selected строго у ja/ty/my/wy, fixedGender только у остальных с корректной категорией, уникальные option IDs m/f и наличие трёх tense labels. Диагностика указывает /reference/verbTeaching/... . Pinned tests фиксируют точный текст; semantic validator не запрещает будущую явную редакторскую правку строки.

src/data/course.ts предоставляет read-only courseVerbTeaching. kotlin/shared/src/commonMain/kotlin/polski/data/CourseData.kt предоставляет типизированные VerbTeaching/VerbSubject (или эквивалент) и функцию разрешения gender по текущему feminineGroup либо неизменяемое поле mode, которое использует host; pack validation — единственный источник доверия к JSON. Host не должен копировать девять строк или превращать subject ID в Person через эвристику по label. React и Kotlin Web выбирают full gender labels и full tense labels; React берёт react futureExplanation, Kotlin Web — compact. Desktop/Android/iOS выбирают compact labels/explanation. IosSnapshot.kt строит verbsRows из subjects и добавляет только нужные control/tense/explanation display strings; SwiftUI не читает pack напрямую. Текущий способ рендера и accessibility labels сохранить.
