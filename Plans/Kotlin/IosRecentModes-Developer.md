# iOS recent modes: developer handoff

Date: 2026-11-14. Baseline: `81f8ce7`. Accepted contract: [IosRecentModes.md](IosRecentModes.md). The working tree already contained regenerated Xcode project and scheme changes plus TileBuilder source registration before this implementation; they were preserved. No generated course rows, desktop source, React source, or progress data were changed.

## Delivered

- `IosSession` exposes current-only Cloze actions. `chooseCloze(exerciseId, form)` ignores a stale ID, unknown form, answered question, closed session, and absent/empty session. `IosSnapshot` projects the shared session's current question and hides `correctForm` until answered.
- SwiftUI adds **Подстановка** with Polish sentence semantics, three form buttons, textual and colour feedback, manual navigation and restart. The 1.5-second advance is owned by `ClozeView`; tab departure, navigation, restart, question change, scene inactivity and view disappearance cancel it. Before advancing it checks the current tab, question ID, and index.
- Settings offers the existing `TileBuilder` answer mode. The shared preference enum now accepts that wire value; the iOS bridge restores it from defaults. Existing Oral/Typed values and missing-value default remain intact. Other hosts still present their existing controls.
- `ClozeView.swift` was registered in `generate_project.rb` and incrementally in the current project, without regenerating the dirty project/scheme.
- Follow-up after independent acceptance: entering Cloze during `Loading` now shows a loading state and reselects Cloze once the existing store reports `Ready`, so its shared session starts. TileBuilder's native Check button now dispatches the existing `tileCheck` command instead of `reveal`; this follows the shared `TileAction.Check` path and shows the evaluated result even when the first card still has a pending prediction prompt.
- A second independent TileBuilder failure isolated a bridge serialization defect: `builder.result?.let { put("result", ...) } ?: put("result", JsonNull)` wrote a real result and then replaced it with JSON null because `put` returns the previous value. `IosSnapshot` now uses explicit branches. The focused bridge test exercises wrong placement, the projected error and its explanation.
