# Матрица React → Kotlin: эталон и текущая проверка

Эта матрица фиксирует исторические частичные gate исходной миграции. После [перехода на две видимые оценки](BinaryRatingUXPlan.md) текущий интерфейс предлагает «Повторить» и «Вспомнил»; четыре значения FSRS сохраняются в старых данных и доменных fixtures. Упоминания четырёх кнопок/путей ниже описывают прежний baseline, а текущая виртуальная приёмка ведётся по [финальному handoff](FinalVirtualAcceptanceBlueprint.md) и [плану курсов](CoursePacksPlan.md).

На 24 сентября [независимая адресная матрица](FinalVirtualAcceptance-Tester.md) и [source/build manifest](artifacts/final-virtual/manifest.json) дополнены финальными виртуальными iPhone/iPad/Mac результатами. Строки ниже остаются историческими `PARTIAL PASS`: выполненный сценарий на одном target не доказывает весь прежний cross-product; физические/IME/assistive gates и Mac packaged narrow-window UI открыты.

Эталон — React из `df59774e153a5bdf590fe27bd8780c7bd5457a26`. JSON в [`tests/fixtures/kotlin-parity`](../../tests/fixtures/kotlin-parity) содержит вход, полный ожидаемый результат и provenance. `npm run fixtures:generate` воспроизводит файлы; `npm test` перепроверяет результат через реальные exports и хэши исходников. Динамический `Exercise.id` записан как `<generated-id>`; генератор отдельно проверяет непустоту и уникальность ID внутри цепочки. Поля FSRS сохранены как JSON без округления. Согласованная погрешность Kotlin для floating point пока не определена.
