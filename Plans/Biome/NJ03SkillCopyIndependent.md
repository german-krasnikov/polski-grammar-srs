# NJ03 independent skill-copy expectation

Status: **test-only freeze, before `SKILL_COPY` authoring or live cutover**. Baseline `biome/full-port-2026@f3892033e3e25d8895eaf92624d60bdc714c7c37`. The complete expectation is [NJ03SkillCopyIndependent.cases](NJ03SkillCopyIndependent.cases); [NJ03SkillCopyNegative.cases](NJ03SkillCopyNegative.cases) declares deliberate failures. `python3 scripts/check-nj03-skill-copy-freeze.py` runs the read-only checker against the historical old sources. No candidate generator, Gradle task, production Kotlin, or application writer is involved.

The corpus freezes exactly **16 en-ru + 16 pl-ru skill records, 1,296 ordered nodes**. Each `SOURCE` row fixes the SHA-256 of the whole old input. The Polish v1 `courses/pl-ru/course.json` is the historical owner, and the checker requires its complete ordered skill subtree to equal the derived `courses/pairs/pl-ru/pair.json` projection. The English pair is the old English copy owner. The two old language curricula supply independent ID/order/level/prerequisite references. All five sources have fixed hashes in the checker and the corpus; the corpus and negative cases have separate fixed byte seals. The files are read only as historical controls; the checker emits no JSON and writes no application data.

`SKILL` fixes 1-based order and the exact ID. `NODE` is a preorder tree of every old skill field, with path, kind, and value. `OBJECT` lists keys in source order, `LIST` records its size, `TEXT` carries readable Unicode plus decoded UTF-8 byte count and SHA-256, and `BOOL`, `NULL`, `INT`, `EMPTY` and `LIST 0` remain distinct. The text escape set is exactly backslash, LF, CR, and tab; an unknown escape is rejected. The checker compares **all** nodes, including source object-key order and fields beyond the eventual copy declaration, against the sealed old source. A missing field cannot silently become null, an empty string, or an empty list. No expected value is derived from a new DSL or generated Kotlin output.

The observed field-presence contract for **each of the 32** old skills is:

- Root keys, in order: `id`, `title`, `group`, `level`, `formula`, `theory`, `hint`, `prerequisites`, `focus`, `methods`, `styleContent`. `id`, `level`, and `prerequisites` belong to `SkillSpec`; the others are copy/presentation facts. All five top-level copy text fields are present strings. `prerequisites` is an ordered list, empty in 2 English and 6 Polish records.
- `focus` is a present record with `before`, `after`, both strings. `methods` is a present record with `logic`, `situations`, each a record of ordered `introduction`, `promptLead`, `introduce`, `retrieve`, `feedback`, `review` strings. No focus or method field is null/absent in this baseline.
- `styleContent` is present on **every** old record, with ordered `nativeParallel`, `examples`, `why`. The optional `rule`, `table`, `scene` are absent on all 32; absence here is not a present null or empty value. `why` is a present string. All `nativeParallel`/`examples` lists are present and nonempty. The 16 English `nativeParallel` lists have one record each; the Polish lists have one (7 skills) or two (9 skills). English native-parallel key order is `native,target,matches,note`; Polish order is `native,target,note,matches`. `matches` has both true and false values. English `examples` have two entries except one with three; Polish examples have two each. Text is retained byte for byte, including Polish/Russian diacritics, typographic punctuation, spaces and arrow glyphs.

The seven negative cases exercise unknown curriculum reference, changed order, duplicate ID, invalid escaping, dropped field, text→null and text→empty substitutions. They must each fail with the named reason; the baseline must pass before any candidate comparison. To verify an implementation, parse candidate typed facts or Kotlin projection **separately**, then compare every observable field and ordered collection to this frozen corpus. A fresh corpus made from candidate output is not evidence. This freeze does not prove a Kotlin host ran or that the live `PackEngine` switched sources.
