## Case notation

Each `CASE id` ends at `END`. `source` cites a requirement. `arms A B C` means the same typed expectation applies to all arms. A `tree` block is an ordered, indented tree: `map`, `list`, `string`, `i64`, `f64bits`, `bool`, `null`. A named child begins `key <quoted escaped text> =>`; a list item begins `item =>`. `string` and `key` quotes use only `\\`, `\"`, `\t`, `\n`, `\r`, `\uXXXX` (uppercase hex) and literal printable UTF-8. Escape pairs are interpreted as UTF-16 code units, so `\uD800` is a lone high surrogate. `absent <path>` asserts no child, distinct from null. `f64bits` is exactly 16 lowercase hexadecimal digits. `i64` is exact decimal, not a floating-point value. `order` lists decoded keys in required order, not implementation sort output.

`input` is a byte oracle. `utf8-lines` means the displayed following lines joined with LF and **one final LF**, with no indentation or escape processing. Literal U+2028/U+2029 in P07 A are text within one LF-delimited row. `utf8-lines-terminal-ht` is the same, except a terminal `<HT>` on a line denotes one final byte `09`; the marker is not part of the wire. `hex` is whitespace-separated exact bytes (`empty` means zero bytes); `utf8-literal` means exactly the quoted printable text with no LF. `NOT FROZEN` means there is no runnable byte oracle. `derive A <id> <edit>` denotes a negative mutation of an independently frozen A byte stream, including a digest recomputation only when stated. This is a fixture operation, not an encoder result. `expect` names the observable result. A SHA-256 digest in an A/C example is calculated from the independently typed prefix through its final LF. An arm's parser must reject a semantically defective stream even if its digest is recomputed correctly.

The A header's wire/schema version, tags and escape spelling are specified in `TextWireDesign.md`. All **12 of 12** A tree cases and **12 of 12** C tree cases now have canonical bytes. All **12 B tree bytes remain NOT FROZEN** pending the pinned library-printer feasibility gate. The new bytes preserve every pre-existing typed expectation and P01–P03 A oracle. Their source is the frozen tree blocks, A grammar in `TextWireDesign.md`, and C grammar in `TextWireFreezeAmendment.md`. Each prefix was authored literally in preorder, then SHA-256 was calculated over that prefix through its final LF; no candidate codec supplied an expectation. P07 A prints U+2028/U+2029 literally because they are outside A's excluded control ranges. The separate fixture checker decoded the literal prefixes and compared exact UTF-16 units, child order, framing and digests for 12 A and 12 C cases. This check validates fixture consistency; it is not candidate execution or independent reviewer approval. A/C lack numeric depth/row/string/total-byte ceilings; N26 cannot have an exact byte or boundary oracle until those limits are fixed. N16's malformed A/C bytes are now frozen; B remains NOT FROZEN. Document schema field order/version and receipt syntax are not yet accepted, so domain and transaction cases record semantic states, not fabricated save bytes.
