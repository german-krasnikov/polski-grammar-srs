## Smallest useful fixture experiment: English `prep:role`

The one-row, seven-Case `role` preposition is the smallest **nontrivial** form family: `neg:not` has one invariant output but cannot probe feature-key completeness or intentionally empty text. Use a new project `PREPOSITION` construct/type and one fixture source under an isolated test directory; use existing Core typed record and `Case` profile patterns. Do not add a shared Core keyword. In this fixture path the typed source is the **only generator input** and the old `prepositions.json` is a sealed read-only historical oracle, excluded from generator/Gradle/runtime inputs; the default application stays on its old owner. This is neither a second *live* authority nor a live migration. A strict repository-wide single-authorship/no-JSON acceptance cannot be claimed until the old preposition authority and whole English writer are retired in the full transaction.

An independent tester freezes a new plain-text `.cases` corpus before authoring: exact ordered `Subj,Obj,In,With,To,About,Of` entries (`"","","in","with","to","about","of"`), both empty-versus-missing distinctions, case-sensitive IDs, `prep:role` lookup outputs, and one-slot `ConstructionRealizer` text/spans for `In` and `Obj`. The latter uses a tiny typed test `ConstructionTemplate` with category `prep` and required `Case`; it is scenario setup, not another course realization table. Run the real `TableMorphology.form` for all seven bundles, plus unknown Case and missing lexeme failures. If the accepted typed language profile is unavailable, do not claim Core Case-reference validation; the independent corpus can still prove literal shape and consumer lookup, with the profile-dependent check pending. Do not reuse `EnRealizationTest`'s hand-authored preposition morphology table as the oracle for this candidate; later replace that fixture's duplicated preposition row when the full typed consumer path is switched.

Do not invoke either `build-pack*.mjs`, `pack:migrate:v2`, `generateFormsFixtureSource`, or any old JSON-producing Gradle task for this fixture proof. Selected/executed/skipped counts and the exact generated-output hashes go in the receipt; currently all are **NOT RUN**.
