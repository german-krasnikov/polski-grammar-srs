# Biome capability map for the no-JSON Polski migration

Status: **read-only architecture audit; no compiler/product implementation or test run is claimed**. Product source reviewed at `biome/full-port-2026@044bcf0`; compiler source reviewed at `biome-dsl@401a88c3`. Follow [NoJsonFullPortPlan.md](NoJsonFullPortPlan.md), [NoJsonAcceptance.md](NoJsonAcceptance.md), the independent [NJ02 cases](NJ02IndependentCases.md), and [ProjectMigratioPrincipals.md](../../../../Python/biome-dsl/AI/ProjectMigratioPrincipals.md) P2/P4/P7/P8/P10/P13/P15–P18/P23/P24. “Proven” below means an existing compiler code path or checked-in test/project demonstrates that capability, **not** that it has run against Polski on this revision. The owner's prohibition covers application-owned authored, generated, intermediate and runtime JSON, even when general Biome permits machine JSON; tool manifests and frozen, input-only legacy user JSON migration fixtures are the narrow exceptions.

**Selection rule:** classify the intent and its owner first. Try the matching existing Biome language and public consumer path before adding syntax: Core declarations for facts/types/references, Logic for shared decisions, FEATURE for model state/actions, FLOW for ordering/resource lifetime where the target exists, and TEMPLATE/project generation for output. A small executable experiment must show a specific missing guarantee; only then extend that language's reusable mechanism and prove it on a separate real consumer. Compare at equal guarantees with a static native helper and amortize the DSL definition across actual uses. Native IO, codecs, FSRS arithmetic and platform effects stay native unless a measured shared rule earns a DSL home. This does not mean using every DSL surface in every subsystem.

## Owner boundaries and next measured decision

The current product's live English curriculum route is `courses/lang/en/curriculum.json` → `kotlin/shared/build.gradle.kts::generateCoursePackSource` → `generatedCurriculumJsonByLang` → `kotlin/shared/src/commonMain/kotlin/polski/training/Curriculum.kt::parseCurriculum` and `core/PlEngine.kt::PackEngine.skills`. Kotlin `SkillSpec`, `FeatureFocus` and `LexicalFilter` live in `kotlin/core-model/src/commonMain/kotlin/polski/core/model/FeatureBundle.kt`. React `src/data/course.ts` imports **Polish** `courses/pl-ru/course.json` into its different presentation `Skill` (`src/types.ts`); no existing TypeScript `SkillSpec` or live English React curriculum consumer was found. Generated TS values are a compiler/output contract probe until a real product consumer is named and executed. Exercise recipes and grammar facts can share typed declarations where they truly own repeated content; native `core-engine/ExerciseGenerator.kt`, TS exercise generation and host adapters still need independent behavior checks. `kotlin/shared/src/commonMain/kotlin/polski/srs/{FsrsMath,FsrsScheduler}.kt` and the corresponding TS FSRS library are arithmetic/SDK mechanics; compare any recurring policy decision separately rather than forcing the arithmetic into Logic. New progress/vocabulary/preferences text codecs, legacy read-only migration, file/localStorage/NSUserDefaults/Android writes and Apple snapshots remain native mechanics/host contracts unless a substantive shared rule earns a DSL source under P4/P8; see [TextWireDesign.md](TextWireDesign.md).

**Next bounded step:** run the isolated [NJ02Blueprint.md](NJ02Blueprint.md) typed A/B/C comparison on frozen curriculum E1/E2/E3, the separate T1 printer text and negative cases. A is a general Core record/list declaration candidate based on the existing one-level binder; B is a pinned established non-JSON text format plus strict schema; C is a static native builder. Give all three the same independent values, diagnostics categories, TS/Kotlin typed outputs, no-JSON freshness and runtime assertions. Count one-time Core/template/printer cost once, marginal cost per actual use, authored/generated lines, semantic edit sites, review/compile/startup/runtime cost and P23 scaling. A TOML or native source can be a serious P8 comparator but is not automatically fulfilment of the owner's biome-DSL authoring goal; record any P4 exception. Do not claim an arm, syntax, backend, clean CI or full app port has passed from this audit, Stage 1 flat rows or generated text alone. No code/test execution was performed for this document.
